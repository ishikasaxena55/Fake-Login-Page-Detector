# Fake Login Page Detector

## Overview
Fake Login Page Detector is a cybersecurity awareness project developed using HTML, CSS, and JavaScript. It helps users identify suspicious URLs and potential phishing websites by analyzing common phishing indicators.

## Features
* Suspicious URL Detection
* Risk Score Calculation
* IP Address Detection
* URL Shortener Detection
* Security Recommendations
* Scan History Tracking
* Cyber Safety Tips
* Progress Bar Risk Meter

## Technologies Used
* HTML
* CSS
* JavaScript

## Live Demo
https://ishikasaxena55.github.io/Fake-Login-Page-Detector/

## Project Purpose
This project helps users become aware of phishing attacks and unsafe websites by providing a simple URL analysis tool.
